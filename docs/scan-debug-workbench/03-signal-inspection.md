# 阶段 03：原始信号检查、冻结与比较

> 先读 [README.md](README.md)、阶段 02 的采集来源契约与实施报告。

如果某个数据接口尚不支持所需信息，显示清楚的不可用原因，并将最小接口扩展单列；不要从状态字符串解析出虚构的结构化数据。

## 2. 03A：原始数据到检查视图

### P3-01：确定唯一的数据源与坐标

复用当前 `IScanImageDecoder`／等价原始读取接口；先验证当前路径是设备原始数据还是经归一化／对齐的通道数据。[S4]

- RAW 统计默认取设备原始单通道样本，放在 Gamma、白点映射、颜色合成之前。
- 只有合成／处理后数据时，不把它标为原始 ADC。可以禁用 RAW 页签并解释来源限制。
- 一次结果同时绑定采集标识、pass／逻辑通道、原始行列范围、有效行数和结果版本。
- 复用现有解码后的坐标空间、ROI clamp 与端点约定；先确认 `EndInclusive` 等含义，不在绘图和统计里各用一套。
- 不硬编码 7592 等示例宽度、不假定反向输片与显示坐标相同；使用数据尺寸与真实变换关系。
- 流式数据只读取已完成且稳定的区域，不能越界读取未完成行，也不能无锁遍历仍在修改的缓冲区。

为了获得稳定数据，可在现有安全发布点取得受控快照、只读所有权或有界拷贝；必须解释同步边界。不要求每个 USB 回调复制整帧。

### P3-02：线剖面

原生工具区选择“图像／线剖面”；已有瀑布显示继续保留，不用新线剖面替换旧功能。

默认画当前选定原始行的每列样本，横轴为真实列坐标，纵轴为 RAW ADU。提供行号与 ROI 范围的明确说明。多行平均可作为后续模式；若本轮实现，必须写清参与行区间和平均方式，不能叫单行。

允许分开绘制偶数列与奇数列；映射未经确认时图例只写偶数／奇数，不能直接叫 ADC1／ADC2。映射有效时可附带对应关系。

数据点超过可见像素宽度时，可采用保留局部极值的可视化聚合。聚合只影响绘图，统计仍基于完整选定原始样本；不得使用简单抽点后的数据计算饱和率或漏掉尖峰。

新图表如支持拖选 ROI，复用现有验证／应用入口，不绕过 ROI owner。最小实现也可使用已有数值 ROI 编辑，无需在 03A 扩展复杂 pointer 交互。

### P3-03：统计定义

定义当前统计域为：一个确定通道、pass／采集版本、一个已说明的原始行区间，以及当前列 ROI。显示参与样本数 `N`。

| 指标 | 定义 |
| --- | --- |
| 最小值／最大值 | 统计域内全部有效 RAW 样本的 min／max |
| 均值 | `sum(raw) / N`，显示格式化不能改变内部精度 |
| 饱和比例 | 当前 16 位原始满量程样本数 / N；阈值与分母必须显示或可查看 |
| 直方图 | 对同一统计域作固定分箱，不使用显示灰度值 |
| 偶奇列差异（可选） | 分别计算两组均值后求差，注明统计含义，不自动判定 ADC 缺陷 |

沿用实际模型位深；当前 RAW 16 位场景的上端满量程为 65535。若后续模型明确不同位深，阈值从模型取得，不把“>= 某显示白点”叫作 ADC 饱和。

实现中使用足够宽的累加类型和长度检查，避免大 ROI 溢出。无有效样本时显示“无有效数据”，禁止除零、输出假 0 或 NaN。坏缓冲区必须通过现有解码校验拒绝，不静默跳过后冒充完整统计。

03A 不显示“时域噪声”数值。空间样本的离散程度与同一位置重复采样的波动不同；后者需要明确重复测量条件。输片中的不同图像行不能自动当成同一像素的时间重复样本。

### P3-04：一致性与后台计算

UI 中图像、统计和来源信息不能各自自由取“最新一份”。允许图像先展示、统计后台计算，但在匹配结果到达前必须显示“正在计算”，不能把旧统计放在新图旁且不标记。

将工作标识至少关联采集版本、通道／pass、行范围、ROI 版本。调参、换图、切通道、ROI 改变或导航离开后，取消或丢弃过期计算结果。

后台计算不直接更新 WinUI 对象；通过现有 dispatcher 发布。已有 UI 线程专属预览缓冲区不能被直接移到 `Task.Run` 并发复用。

刷新策略有界：允许合并过时的显示／分析请求，但不能丢弃正式采集、保存或导出数据。建议最多一个计算任务加一个最新待处理请求；具体采用方式需写入报告。

### P3-05：性能与限制

不承诺固定 FPS。记录代表性小样本、当前常用行数、大样本下的计算耗时、分配量和界面响应。持续预览和 ROI 快速调整后，不应形成无限任务队列或单调增长的历史数组。

绘图缓存和分析临时内存必须有清楚所有者与释放时机。需要采样上限或内存保护时，显示实际处理范围；不改变完整采集能力，不把“预览不可用”写成“采集失败”。

大图分层／分块预览不属于本阶段强制工作，不靠提高预览上限掩盖内存问题。

## 3. 03B：冻结和 A 基线

### P3-06：冻结语义

冻结必须同时固定当前图像／图表、原始数据引用或安全副本、统计和采集来源；仅暂停画布重绘不算实现。

现有 preview frame 可能复用像素数组，所以不能只保留 frame 对象引用。[S4]

采集可以继续，设备停止入口仍工作。冻结时显示“显示已冻结，采集仍在进行”或与真实运行状态匹配的文案；采集已经停止后不能继续称“仍在进行”。

恢复时显示当前最新完整结果，不逐帧追赶积压。冻结期间到达的新数据不能改变冻结对象，也不能通过共享缓冲区篡改统计。

断连时可以保留冻结的历史结果，但必须更新设备连接状态。冻结过程中用户改变显示 Gamma，可以对同一冻结 RAW 重新显示；不能改变采集参数来源。

### P3-07：固定 A 基线与比较资格

默认最多固定一个 A 基线，替换前释放旧基线资源。基线保存原始数据必要范围或稳定引用、统计范围及采集上下文，不只是一个浮点均值。

比较规则：

- 通道、坐标定义、几何处理阶段和统计域可对应时，显示 A／当前值及差值。
- ROI 变化后，若两份稳定 RAW 都可访问，可用同一新范围重算两者；否则明确“统计范围不同，不能直接比较”。
- 曝光、增益或照明不同是调参比较的常见目的，不因版本不同就一律拒绝比较；必须列出变化条件，并禁止自动宣称质量更好。
- 不同通道、不可对应的几何范围、原始／合成混合或未知来源不能默认作可解释的同类比较。
- 对焦分数的跨条件比较必须提示限制；均值提高不代表对焦改善。

允许展示不具可比性的两个独立结果，但不能给出“改善百分比”或绿色合格结论。

### P3-08：内存上限与故障

文档化冻结＋当前＋基线的最大保留策略。允许共享真正不可变的所有者，但不能共享可变数组冒充不可变数据。固定失败时保持旧基线并报告错误；不能为此取消采集、修改图像内容或 OOM 后继续显示假成功。

页面离开／当前会话替换时按原生命周期清理订阅和后台计算。历史数据是否保留遵循当前 Page 缓存策略，不因本阶段擅自改掉导航缓存。

## 4. 03C：对焦过程曲线

### P3-09：使用结构化的真实探测记录

先检查自动对焦服务是否已经提供结构化探测数据。如果只有最终结果，允许最小的可选进度记录扩展，不改变现有算法、驱动步骤、评分或最终选择逻辑。

一条记录至少表达本轮任务标识、采样序号、被探测轴／变量、相对指令位置、评分、ROI 和固定采样条件；实际未提供的左右分数不绘制。

整体 Z 搜索、倾斜探测或左右电机独立探测不能强行画在同一条位置轴上。必要时按搜索阶段分组；位置是指令／估算值时明确标注，不叫编码器实测位置。

记录来自同一轮任务。取消或下一轮开始后，迟到点不能进入新曲线。有限记录数和更新合并不能反向阻塞硬件操作。

### P3-10：解释边界

图中标出当前点、最佳探测点、搜索边界和最终采用点。当前服务没有给某项证据时不推断。

分数只有在明确可比较的 ROI、曝光／增益和测量条件下才可解释。不得仅凭左右分数差诊断机械倾斜，也不得顺手修改分数归一化算法。

最佳点落在边界可以提示“可能需要扩大搜索范围”，但不自动扩大范围或继续运动。没有探测数据时显示空态，而不是合成曲线。
