# 2026-10-14 配置编辑与扫描衔接

本文记录配置编辑、保存交接和操作反馈的修改及当时验证范围。当前回归结果和剩余验收见[统一待办](../../TODO.md)；历史通过结果不代替当前保存、身份和通道映射契约的核查。

## 配置输入与保存交接

采集行数改为单向显示、显式提交预设或自定义文本。Esc 恢复当前草稿，空选项变化不反写；页面重入清理取消标记。编辑输入使用独立基线，恢复原值后清除相应修改标记；各通道的无效数字和 ROI 草稿在切换后仍能恢复。

加载配置同步行数、电机、目标行距、起始方向、预热和传送策略。撤销恢复本编辑器拥有的输入基线，保留导入的原始电机间隔及配置通道信息，不覆盖外部通道或手动参考值更新。设备设置初始化前限制自动对焦请求，映射投影完成后重新计算可用状态。

完整配置保存继续进行结构与数值校验，离线本身不作为禁止保存的条件。保存不可用时显示具体检查原因；配置草稿时钟与设备确认时钟分开，曝光范围按实际时钟关系计算。

“保存并用于扫描”只在文件确实保存成功、且仍属于当前页面激活时导航。已保存快照与后续未保存编辑隔离；新导航消费交接，后退不重复使用。离页取消配置载入，旧异步结果不更新新页面；已经开始且不支持取消的本地存储写入仍可能完成。

## 独立编辑草稿

配置菜单增加 `.prismdraft` 的打开与保存，用于恢复空值、无效数字、采集模式和未应用的黑白参考文本。格式包含版本、类型、字段完整性检查及 2 MiB 限制，损坏文件不替换当前输入，也不能作为运行 JSON 导入。

保存草稿保留保存期间的新编辑和上次完整配置快照。打开草稿清除旧扫描交接快照，只恢复编辑器；完成编辑后仍需保存完整配置才能用于扫描。草稿读写不应用设备参数，也不替换校准库。取消、读写失败、页面失效或打开期间继续修改时保留当前编辑，恢复前完整检查所需类型，避免部分恢复。

## 引导、审阅与布局

- 增加“准备配置 → 检查通道与校准 → 检查问题 → 保存并用于扫描”的简短引导。入口只定位或检查，缺参考值作为建议；定位扫描入口不自动保存或采集。
- 采集通道前置，顺序统一为红、绿、蓝、白、红外，并保留物理 LED 映射的显示；传送和高级曝光细节默认折叠。
- 配置检查及保存前重校验失败打开可定位的问题列表，不混入设备运行错误或覆盖真实文件错误。文件选择和确认取消静默返回。
- 保存状态区分编辑草稿、校准库、完整配置与设备应用。属性页精简重复成功提示，长反馈保留完整详情和操作记录。
- 选择其他配置文件直接打开文件选择器，取消保留暂存导入或导入错误；实际替换未保存编辑仍需确认，并在审阅面板显式应用。
- 属性与通道详情保留预览，问题列表随可用宽度停靠或覆盖，但不遮住任务导航、流程引导和固定运动操作栏。文件通知避开检查列表与停止入口。
- 方向名称根据可靠映射显示对焦或走片语义；未映射时保留方向编号。显示名称不改变原 Dir0/Dir1 协议值。

空预览比例、检查列表停靠门槛及返回滚动行为已有后续实现变化，具体差异和待定设计见[统一待办中的规范冲突](../../TODO.md#兼容性与设计差异)。本记录保留布局意图，不将历史门槛作为当前验收值。
