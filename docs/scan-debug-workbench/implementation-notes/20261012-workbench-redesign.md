# 2026-10-12 工作台改版

记录范围为 2026-10-12 至 2026-10-13 的工作台与布局修改。以下描述当时的实现和验证，不表示当前版本全部通过；后续行为变化与回归状态见[统一待办](../../TODO.md)，设计原则见[工作台设计](../workbench-design.md)。

## 观察与编辑分离

观察区增加显示冻结和单槽基线 A。快照复制图像、线剖面、直方图、行号、范围及采集来源，可在 A 与当前显示间切换或清除 A。冻结只改变观察对象，采集继续使用实时缓冲；旧快照不读取实时像素或列均值。每份显示副本限制为 64 MiB，超过限制时说明原因而不停止采集。

RAW 分析继续读取原始 packed row；显示反相不改变 RAW 统计。观察范围与算法范围分别管理，图像拖选或数字输入先修改观察范围，再由显式操作填入 ADC 或对焦草稿，最后通过各自应用命令提交。复合图像坐标不直接冒充单通道 RAW 坐标。

来源摘要保留未知来源、参数写入记录变化、历史设备会话和通道不匹配等提示。冻结和基线固定各自的来源与统计；Gamma、白点等实时处理控件按观察状态限制编辑，避免把实时处理结果混入快照。

## 工作区与入口调整

| 区域 | 变更与保留的语义 |
| --- | --- |
| 观察工具 | 冻结保留直接入口；基线、选区、显示设置、叠加和图像导出归入明确分组。无样本时收起不适用的控件。 |
| 状态与反馈 | 样本状态、短来源及尺寸集中到底栏；配置检查和问题入口合并，反馈入口显示未确认数量，真实未解决错误仍可见。 |
| 校准候选 | 审阅替换左侧参数内容，报告独立滚动，接受、接受并保存、恢复、取消四种处理保持独立。 |
| 配置属性与工程工具 | 配置属性保留基本信息和设备设置；工程工具集中设备映射测试、会话照明测试及原始灯光诊断。四任务编辑和工程测试不重复维护输入。 |
| 辅助面板 | 配置属性、工程工具及通道详情只替换参数区，保留任务导航和预览；普通与辅助面板分别维护分隔比例。 |
| 文件身份 | 显示实际打开或成功保存的文件名；另存为确定名称后再序列化。取消文件选择、未应用的导入审阅不修改当前身份。 |
| 问题定位 | 非传送模式下定位传送参数时，临时展开相应字段而不改变采集模式；离开采样任务后清除临时展开状态。 |

标题、文件摘要、设备状态与操作按钮重新对齐。并排字段使用共用标签行和输入行，保留本地化与辅助功能名称；运动速度单位完整显示。工具栏根据实际语言内容和可用宽度换行，长文件名、问题计数或错误文本变化不应挤掉连接、反馈和停止入口。

采集、会话仲裁、自动校准、自动对焦算法、硬件协议及 DNG 格式没有因这次界面改版重写。观察状态沿用页面停用和清理路径释放。单槽显示基线并非完整 RAW 历史库，也没有加入自动参数推荐或完整数值差异分析。

## 验证与限制

| 范围 | 当时记录的结果 |
| --- | --- |
| 构建 | Windows QA 与普通 x64 Debug 构建成功，保留已有发布配置警告。早期跨平台源码编译不作为 WinUI XAML 构建通过的依据。 |
| 托管回归 | 包含一次 1651 项完整运行：1647 通过、4 项因历史验收材料缺失失败。其后的布局与反馈修订另做定向检查，不能把定向结果写成新的全量通过。 |
| 原生离线布局 | 检查中英文、浅深色、紧凑与常规内容尺寸，覆盖候选审阅、冻结/基线、RAW、辅助面板、文件身份、问题定位和工具栏。分别记录实际内容区与像素尺寸。 |
| 真实窗口走查 | 观察整体框架、留白、状态和单位显示，检查部分入口及返回流程；原生 XAML 渲染与桌面窗口观察分别判断。 |

原生检查使用隔离的离线显示数据；合成 RAW 数据只用于读数和图表呈现验证。曾检查 125% 和 200% 显示缩放，尚未建立完整缩放、高对比度及键盘遍历矩阵。未连接扫描仪验证真实采集、运动、照明、设备停止或原生 DNG 输出。

后续仍需验证当前版本的保存与导航行为、观察性能、快照总内存预算和实机来源一致性。返回时的滚动策略以及空预览布局已有后续差异，按[统一待办中的规范冲突](../../TODO.md#兼容性与设计差异)处理，不以本记录冻结旧布局。
