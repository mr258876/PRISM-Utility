## 1. Baseline and Design Contract

Before this round, `DESIGN.md` described a compact identity/run area, four tasks, task-owned scrolling and Fluent spacing, but prescribed old footer and typography rules. This round replaced those ScanDebug-only rules with a 28/16/14/14/12 semantic ramp and distinct run/observation roles. Existing page resources `ScanDebugPagePadding`, `ScanDebugCompactCardPadding`, `ScanDebugInlineSpacing`, `ScanDebugSectionSpacing` and `ScanDebugSectionCardStyle` remain in use.

Pre-edit `WorkbenchTitleTextBlock` used `BodyStrongTextBlockStyle`; it now uses `ScanDebugPageTitleStyle`. The four task selectors and compact alternatives are preserved. `BasicInfoSection`, `AcquisitionPlanSection`, `ChannelCalibrationSection`, `LiveCalibrationSection` and the existing `MotionContent` bindings remain; the ordinary Motion root is now `MotionTaskSection`, separate from `EngineeringToolsSection` within the same section-index navigation contract.
