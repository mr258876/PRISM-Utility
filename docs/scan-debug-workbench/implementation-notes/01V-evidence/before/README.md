Launched with `PRISM_VISUAL_QA_EMPTY_STATE=1`, which opt-outs of synthetic preview frame, raw buffer, ROI, and pending calibration seeding and selects ordinary sampling. The QA capture service returned read-only geometry requests from the live UI thread. The `emptyStateCapture=true`, `previewFramePresent=false`, and `pendingCalibrationPresent=false` fields were checked on both requests. No device, scan, motor, or illumination command was invoked.
