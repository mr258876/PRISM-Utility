### Navigation and ownership invariants

- Current validation issues map to basic info (0), acquisition (1) and channel calibration (2); ROI issues map ADC/reference to channel calibration (2), focus to live calibration (3). Preserve `TryResolveCurrentFilmProfileNavigationTarget`, `TryResolveRoiNavigationTarget`, `x:Name`/AutomationIds, `FindName` deferred illumination/motion and the guarded selector-sync path when remapping the view.
- Page remains cached and owns its `Loaded`/`Unloaded`, VM Attach/Deactivate, dialog `XamlRoot`, event subscriptions and one CanvasBitmap/Canvas tree. Manual focus pointer release/cancel/capture-lost must remain reachable through all responsive states.
